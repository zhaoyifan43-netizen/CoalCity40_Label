大同2023：Windows QGIS全域预标注与复核

一、准备
1. 使用QGIS 3.x正式版，建议3.40或更新的3.x版。无需另外安装Python或pip包。
2. 将本工具包完整解压到D:\CoalCity\qgis_tools。
   应看到D:\CoalCity\qgis_tools\01_prelabel.py和02_export_reviewed.py。
3. 原始数据放在D:\CoalCity\input。脚本会递归查找，因此以下两种都支持：
   D:\CoalCity\input\CN01_B04.tif
   D:\CoalCity\input\CN01_Datong\CN01_B04.tif
   目录中只能有一份CN01_B04.tif，避免不同版本混用。
4. 同目录须有B02/B03/B04/B08/B11/SCL六个tif与CN01_CUFR_circle_UTM.geojson。
   RGB.png不是地理参考基准。NDVI/NDWI由波段重算；NDBI也自动计算。
5. 本批Sentinel-2整数波段按10000缩放。若使用的是自行转换到0—1的反射率，须将脚本REFLECTANCE_DIVISOR改成1.0。
6. 先保存当前QGIS工程及图层编辑。脚本成功后将打开一个新生成的工程。
   不移动/覆盖原数据。每次运行创建独立带时间戳输出目录，不覆盖以前的复核工作。

二、运行
1. 在QGIS菜单选择“插件→Python控制台”（通常可用Ctrl+Alt+P）。
2. 在底部带>>>的单行输入框粘贴以下整行，回车：

from pathlib import Path; exec(compile(Path(r'D:\CoalCity\qgis_tools\01_prelabel.py').read_text(encoding='utf-8'), '01_prelabel.py', 'exec'))

3. 控制台会打印进度。矢量化可能较慢，期间不要重复运行或强制退出。
4. 成功后输出位于D:\CoalCity\output\CN01_prelabel_时间戳\，并自动打开CN01_review.qgz。
   如果项目显示异常，可手动打开该qgz。不要移动input目录，否则真彩色VRT会找不到原波段。

三、输出说明
CN01_PRELABEL_NOT_FINAL.tif：全域规则候选，绝非最终真值。0—6是候选，254是待判定，255是区域外或云影/薄云候选。
CN01_review.gpkg / label_polygons：用于编辑的全域多边形；每个都verified=0。
CN01_review_reasons.tif：复核原因位掩码，各值可以相加，不是概率或置信度。
  1全部需复核，2云影/薄云，4农田林草混淆，8建成区裸地混淆，16水体/阴影/水体类型，32设施1km排查范围，64待判定，128类别边界。
facility_review_points.geojson：上传调研中的8个设施线索，只用于定位，绝不是设施范围。
CN01_CUFR_mask.tif：圆形范围1，区域外0。
CN01_RGB.vrt：从B04/B03/B02构建的地理参考真彩色。
run_report.json：算法、参数、数量及限制记录。

四、如何复核（所有区域都要复核，先处理困难区域）
1. 在图层面板右键“待复核多边形_编辑此图层”→打开属性表。
2. 先筛选：class_id IN (254,255)，再处理农田、林木、建成区和煤炭设施周边。
   如要只看未完成，筛选 verified = 0。取消筛选可显示全部。
3. 在图层面板取消勾选“全域候选_未复核”，这样编辑时不会把下方静态栅格误当成已同步修改的结果。
4. 点击铅笔进入编辑模式；借助分割要素、顶点工具修改边界，用属性表改class_id。
   开启捕捉和拓扑编辑，避免边界空隙或重叠。放大至接近10m像素尺度检查。
5. verified=1只能在你实际看过、修正并确认该多边形后填写。不要整层批量标成1。
6. evidence字段记录来源、访问日期、证据年份及用途。煤炭类必须有功能证据，13记录具体地物，255记录Ignore原因。
7. 如果一个原多边形需要分成不同类别，先分割，再分别填写class_id/verified/evidence。
   加入新要素也必须填写这些字段。云影必须保留显式多边形，不能以删除要素代替Ignore。
8. 删除/重画后必须保持全覆盖，不能把未完成区域设成255。254必须在确认实际类别后消除。
9. 小于4像素斑块、道路20m宽度与连通性、难以判定的混合边界按原标注说明处理。
10. 保存图层编辑，退出编辑模式，保存工程。

类别编码
0高密度建成区；1低密度建成区；2农田；3林木/高密度植被；4草地/稀疏植被；5裸地；6普通水体；7道路；8可观测活跃采掘区；9煤矿废弃物堆场/排土场；10采煤沉陷水体；11煤炭加工与电力设施；12煤炭物流；13其他明确地物；255真正Ignore。
自动脚本只建议0—6类；7—13需人工补画/更正，尤其8—12不能按点缓冲圈、黑色外观或阈值赋类。
农田与林木、草地仅凭单期光谱难以可靠分开；0/1候选采用的局部光谱密度代理不是建筑覆盖率，也不是ISA真值。
规则未经大同标签校准，不能据此报告类别准确率。“全域生成”并不等于“全域完成”。

五、保留之前的65处草稿
本脚本不会自动合并以前的草稿，以免重复多边形或旧粗边界覆盖新结果。
你可以将之前草稿包的GPKG作为参考图层加载，但它同样未独立复核。
如要采纳某个旧多边形，先切割/替换工作图层对应区域，确保没有重叠，再复制类别和证据；不直接整层叠加后导出。

六、复核完成后导出正式文件
仅当所有要素实际已复核、verified=1、class_id在0—13和255中，并已保存图层和工程后，在同一QGIS工程Python控制台运行：

from pathlib import Path; exec(compile(Path(r'D:\CoalCity\qgis_tools\02_export_reviewed.py').read_text(encoding='utf-8'), '02_export_reviewed.py', 'exec'))

导出器会检查未复核要素、待判定编码、功能证据、几何有效性、像素漏标及重叠、矢量重叠、输出网格。
任一检查失败都会停止，不产生新的正式文件。
成功后在当前输出目录的reviewed_export_时间戳下生成CoalCity40_CN01_label.tif与export_QC.json。
这些技术检查不能证明语义正确或边界精度达标，仍需按原说明做独立质量验收。
最后请保留整个输出目录（尤其GPKG、工程和填写的evidence），并将成果上传到指定资料库文件夹；脚本不会自动登录或上传资料库。

七、遇到报错
找不到B04：确认路径、解压完成、只有一套大同文件。
网格不一致：不要直接运行或自行强制修改投影；先对齐数据。
当前工程未保存：先保存，再运行。
无法写入：确认D盘有空间、output可写。
ModuleNotFoundError: qgis/osgeo：你在普通Python而非QGIS控制台运行了脚本。
其他报错：复制控制台完整Traceback，不只复制最后一句。保留原始文件，勿将失败运行的部分输出视为最终结果。
